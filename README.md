 # Nifty 100 Financial Intelligence Dashboard

## Overview

A financial analytics dashboard for Nifty 100 companies built using Python, SQLite, Streamlit and Plotly.

---

## Features

- Company Profile
- Financial Screener
- Peer Comparison
- Trend Analysis
- Sector Analysis
- Capital Allocation
- Annual Reports
- Valuation Dashboard

---

## Technologies

- Python
- Streamlit
- SQLite
- Pandas
- Plotly
- OpenPyXL

---

## Folder Structure

```
src/
dashboard/
analytics/
database/
data/
output/
```

---

## Installation

```bash
pip install -r requirements.txt
```

---

## Run Dashboard

```bash
streamlit run src/Dashboard/app.py

```
